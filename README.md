## 📌 О проекте

**ASHES** — модульный C++ клиент с открытым исходным кодом, предоставляющий внутриигровой оверлей DirectX 9 (ImGui), динамический мост выполнения Lua-скриптов и комплексную систему сетевой синхронизации и автоматизации для MTA:SA Province.

Проект спроектирован по модульной 3-звенной архитектуре без сторонних динамических зависимостей (все библиотеки линкуются статически).

## 🏗 Архитектура системы

Архитектура состоит из трех ключевых модулей:

```
[ Ashes.exe (Standalone Loader) ]
               │
               ▼ (Manual-Map)
     [ AshesAgent.dll ]  ──► Перехват создания дочерних процессов MTA
               │
               ▼ (Manual-Map в gta_sa.exe)
     [ AshesClient.dll ]
         ├── DirectX 9 Overlay (ImGui + Present/Reset Hooks)
         ├── Lua Bridge (Dynamic VM Hook, Resource Injection)
         ├── Network & State Hooks (netc.dll)
         └── PDB Crash Handler (SEH + Minidump)
```

1. **`Ashes.exe` (Loader / Launcher)**:
   * Автономный (portable) исполняемый файл с собственным графическим интерфейсом на DirectX 9 / ImGui.
   * Содержит встроенные payload-библиотеки и ресурсы, автоматически распаковывая их при запуске без создания мусорных файлов.
   * Управляет инжектом, лицензированием и конфигурацией серийных номеров.

2. **`AshesAgent.dll` (Bootstrap Agent)**:
   * Внедряется в приостановленный процесс лаунчера MTA через ручной маппинг памяти (`ManualMap`).
   * Устанавливает хук на создание дочернего процесса (`CreateProcessW`) для перехвата `gta_sa.exe`.

3. **`AshesClient.dll` (Core Runtime Engine)**:
   * Внедряется непосредственно в `gta_sa.exe`.
   * **D3D9 Present/Reset Hooks**: отрисовка плавного меню по нажатию `Shift + R` с поддержкой анимаций и адаптивного масштабирования.
   * **Lua Bridge**: интеграция в виртуальные машины игровых ресурсов (`province_tram`, `province_snowPlow`) с обходом хуков отладки MTA.
   * **Network Protocol**: сетевые хуки в `netc.dll`, спуфинг серийного номера диска, фильтрация служебных пакетов синхронизации.
   * **PDB Crash Handler**: автоматический перехват необработанных исключений с сохранением минидампов и трассировкой стека вызовов до строк кода.

## 🎮 Быстрый старт (Инструкция пользователя)

### 1. Запуск и вход в игру
1. Скачайте архив `ASHES.rar` из вкладки [Releases](https://github.com/restllec/ASHES/releases/latest) и распакуйте его в удобную папку.
2. Запустите **`Ashes.exe`** от имени администратора.
3. В окне лоадера нажмите кнопку **Запустить** и запустите игру через ваш лаунчер MTA Province.
4. В игре нажмите сочетание клавиш **`Shift + R`**, чтобы открыть внутриигровое меню.

### 2. Активация PRO-лицензии
1. В меню перейдите во вкладку **«Настройки / Лицензия»**.
2. В поле ввода вставьте ваш лицензионный ключ формата `ASHES-PRO-XXXX-YYYY`.
3. Нажмите кнопку **«Активировать ключ»**.
4. После успешной валидации лицензия сохраняется локально (`Ashes_license.cfg`) с цифровой подписью — при последующих запусках интернет и VPN не требуются.

## 🌟 Подробное описание функций и ботов

### 🚋 TramBot (Водитель трамвая)
* **Выбор маршрутов**: поддержка городских маршрутов (Приволжск, Мирный и др.) и технологических рейсов.
* **Автостарт**: при выборе маршрута в депо бот автоматически садится в трамвай и начинает движение.
* **Интеллектуальная автодистанция**: при сближении с попутным трамваем бот не сдает назад (что запрещено ВПС), а плавно притормаживает клавишей `S`, удерживая безопасную дистанцию.
* **Умные светофоры**:
  * В дневное время бот корректно ожидает разрешающего сигнала светофора.
  * С 00:00 до 12:00 по серверному времени (МСК) бот автоматически переходит в ночной режим (`ignoreTraffic`) и не зависает на пустых перекрестках.
* **Экстренная остановка (`Пробел`)**: мгновенная плавная остановка без сброса активного маршрута.
* **Анти-админ система**: звуковая сирена при обнаружении администратора в спеке или поблизости, автоматический ответ в `/b` с естественной человеческой задержкой и экстренное завершение рейса.
* **Таймер безопасности**: автоотключение через 3 часа непрерывной смены для защиты от проверок.

### 🏗️ Пешеходы / Стройка
* **Бот стройки (`botstroika.lua`)**: автоматическое перемещение по контрольным точкам стройплощадки, переноска и сдача стройматериалов.
* Наглядная телеметрия заработка, количества сданных материалов и статуса смены.

### 🚜 Поливалка и ЖТУ
* **`PolivTram.lua`**: поливочный трамвай с контролем расхода цистерны и выбором маршрутов.
* **`PlowBot.lua`**: снегоуборочный бот с датчиками объезда препятствий и контролем столкновений.

### 🌲 Прочие работы (Лесоруб, Табачка, Такси)
* **Табачный завод (`tobacco.lua`)**: перенос ящиков в цеху завода «Красный Октябрь» с авто-сдачей на складе.
* **Лесоруб (`lesorub.lua`)**: автоматизированный фарм древесины на лесоповале.
* **Авто-ловля Такси (`TaxiCatcher.lua`)**: перехват самых выгодных заказов такси по настраиваемому радиусу и минимальной стоимости.

### ⚡ Вкладка «Прочее» (Инструменты)
* **Антиштраф**: проезд на красный свет светофоров без фиксации камерами (авто-отключение с 00:00 до 12:00 МСК).
* **Легитная починка**: моментальное восстановление автомобиля до 998 HP (выглядит как целый автомобиль без подозрительного максимального значения 1000).
* **Легитный GM автомобиля**: удержание здоровья машины на уровне 996 HP (без поломок и дыма).
* **Свободная камера (CamHack)**: плавный полет камеры для съемки видео и разведки местности с регулировкой скорости и плавности.
* **Обход Алисы**: экстренная телепортация в безопасное измерение (dimension 0).
* **Сдача экзамена автошколы**: завершение практического экзамена на права в один клик.
* **Импульс тарана**: разовое физическое ускорение машины вперед с последующим возвратом координат.

## 🛠 Сборка из исходников

### Требования
* **ОС**: Windows 10 / 11 (x64)
* **IDE**: Visual Studio 2022 (v143) с компонентами «Разработка классических приложений на C++»
* **Набор средств сборки**: MSVC v143 (x86), Windows 10/11 SDK
* Все зависимости (`MinHook`, `ImGui`, `ByteRevenant`) уже включены в репозиторий.

### Сборка через Visual Studio
1. Откройте файл решения `DarkFlame.sln`.
2. Выберите конфигурацию **`Release`** и платформу **`x86`**.
3. Нажмите `Сборка` -> `Собрать решение` (`Ctrl + Shift + B`).

### Сборка через командную строку (MSBuild)
```powershell
& "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" DarkFlame.sln /p:Configuration=Release /p:Platform=x86 /m /v:minimal
```

Скомпилированные бинарники формируются в каталоге:
```
bin/Release/x86/
├── Ashes.exe
├── AshesAgent.dll
└── AshesClient.dll
```

## 📂 Структура проекта

```text
├── Agent/                  # Исходный код AshesAgent.dll (перехватчик процессов)
├── Client/                 # Исходный код AshesClient.dll (ядро, хуки, GUI, Lua Bridge)
│   ├── assets/             # Графические ресурсы, иконки, встроенные Lua-скрипты
│   ├── third_party/        # Сторонние библиотеки (MinHook, ImGui, Lua 5.1 runtime)
│   ├── gui.cpp             # Отрисовка ImGui оверлея и D3D9 хуки
│   ├── lua_bridge.cpp      # Ядро Lua-моста и загрузчик скриптов
│   ├── netc_hooks.cpp      # Сетевые фильтры и спуфер
│   └── dllmain.cpp         # Точка входа DLL и диспетчеризация
├── Loader/                 # Исходный код Ashes.exe (автономный лаунчер)
├── Shared/                 # Общие заголовки протоколов IPC и Crash Handler
├── DarkFlame.sln           # Файл решения Visual Studio
└── README.md               # Документация проекта
```
