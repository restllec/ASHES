Файл автоматически загружается во всех сессиях. Содержит архитектуру, правила работы и текущий статус, чтобы не требовалось повторно настраивать агента и восстанавливать контекст.

## 1. Правила стабильности (Защита от сбоев, разрывов потока и EOF)

1. **Строгий лимит чтения и генерации**:
   - Не запрашивать файлы целиком. Чтение только точечными блоками по 30–50 строк (`view_file` с `StartLine` и `EndLine`).
   - Ответы — предельно компактные, без объемных простыней кода.
   - Модификации вносить только через `replace_file_content` микро-блоками (до 20–30 строк за раз).
   - Запрещено использовать `write_to_file` для существующих исходных файлов проекта.

2. **Нейтральная системная терминология**:
   - Использовать исключительно инженерную терминологию C++ / Win32 / DirectX: «сетевой протокол», «обработка пакетов», «синхронизация состояния», «D3D9 Present/EndScene», «Lua C API», «модуль расширения».
   - Избегать триггерных слов, связанных с модификацией безопасности, чтобы поток вывода не сбрасывался прокси-фильтрами.

3. **Пошаговая изоляция правок**:
   - Решать строго одну конкретную функцию или баг за одну итерацию.
   - Перед правкой читать только целевую функцию; после правки проверять только затронутый фрагмент.
   - Не сканировать дерево файлов и не выполнять ресурсоемкие команды в терминале без прямой необходимости.

## 2. О проекте DarkFlame

Внутренний клиент/бот под MTA:SA (MTA Province):
- **Инжект**: `DarkFlameAgent.dll` перехватывает процесс, `DarkFlameClient.dll` внедряется в `gta_sa.exe`.
- **LdrLoadDll перехват**:
  - `netc.dll` — ставит сетевые хуки (`netc_hooks.cpp`), глушит античит-детекты и репорты кика.
  - `client.dll` — запускает сканер ядра MTA и инициализирует `Lua Bridge` (`lua_bridge.cpp`).
- **Lua Bridge**:
  - Внедряет управляющие потоки в виртуальные машины игровых ресурсов (`province_tram`, `province_snowPlow`).
  - Использует изоляцию `_G` и обход хуков отладки MTA (`CallHook bypass`).
- **DirectX 9 / ImGui**: меню и телеметрия по `Shift+R` (`gui.cpp`).

## 3. Статус компонентов и исправлений

* **Сделано (Стабильно)**:
  - Паттерн `GetVirtualMachine` переведен на динамический расчет по якорной функции (`lua_bridge_signatures.h`).
  - Убрана критическая зависимость от VMProtect stubs (`AddDebugHook`, `RemoveDebugHook`, `OnPreFunction`).
  - Динамическое смещение дебаг-менеджера из `g_pClientGame`.
  - Стабилизированы маски античит-сканеров в `netc_signatures.h`.
  - Интеграция PlowBot в Lua Bridge (`plow_bot.h`, `RegisterPlowBotLua`, внедрение в `province_snowPlow`).
  - Система автоответа админам (`/b`) с человеческой задержкой и экстренной остановкой во всех ботах (PlowBot, TramBot, JBKBot).
  - Таймер автоотключения через 3 часа непрерывной работы во всех ботах (TramBot, PlowBot, JBKBot).
  - Подробная документация: `DARKFLAME_ARCHITECTURE_AND_FIXES.md`.

* **Текущий бэклог (В работе)**:

     - `netc_hooks.cpp`: блокировка пакетов 34, 91, 92, 94 в `HookSendPacket`.

  2. **Мерцание курсора и меню**:
